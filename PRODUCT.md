# Product

## Register

product

## Users

Developers and email authors working in a code editor or build pipeline who need to create reliable, reusable HTML email without handing unresolved merge syntax to another template engine.

## Product Purpose

Email Markup provides a typed, component-based source language, compiler, CLI, language server, standard library, and VS Code extension that turn one `.em` document plus one JSON object into complete, CSS-inlined, linted HTML. Success means authors receive accurate source-mapped feedback and dependable editor assistance while automation receives deterministic, secure output.

## Brand Personality

Technical, precise, and neutral. The product should feel dependable and direct, with expert confidence coming from correctness and clear tooling rather than decorative branding.

## Anti-references

Avoid branded campaign-builder aesthetics, generic SaaS ornament, novelty syntax visuals, misleading editor affordances, and features that imply browser-only HTML or CSS behavior the compiler does not support.

## Design Principles

- Make the compiler and language grammar the semantic source of truth.
- Preserve source coordinates and context across every editor feature.
- Keep authoring assistance strict enough to prevent false confidence and quiet enough not to interrupt prose.
- Expose advanced language capability through familiar editor conventions.
- Prefer deterministic, secure behavior over hidden coercion or convenience magic.

## Accessibility & Inclusion

Follow the host editor's accessible interaction, theming, keyboard, reduced-motion, and high-contrast conventions. Do not encode meaning by color alone, and keep diagnostics and language features usable with assistive technology.
